\# 🎲 Ludo Food Delivery



\*\*Ludo Food Delivery\*\* is a Java-based food delivery web application that combines convenient online food ordering with an interactive LUDO game. Users can explore restaurants, browse menus, manage their carts, place orders, and win discount coupons by playing the LUDO game.



\## 🚀 Features



\- 🏪 \*\*Restaurant Listings\*\* — Explore multiple restaurants.

\- 🍽️ \*\*Dynamic Menus\*\* — View menu items for the selected restaurant.

\- 🛒 \*\*Cart Management\*\* — Add, update, and manage food items.

\- 🎲 \*\*LUDO Game\*\* — Play a game directly within the application.

\- 🎟️ \*\*Reward Coupons\*\* — Win discount coupons through gameplay.

\- 📦 \*\*Order Processing\*\* — Proceed through the checkout and order success flow.

\- 🖼️ \*\*Food Images\*\* — Display food images using local project assets.



\## 🛠️ Technologies Used



\- \*\*Backend:\*\* Java, Servlets, JDBC

\- \*\*Frontend:\*\* JSP, HTML, CSS, JavaScript

\- \*\*Database:\*\* MySQL

\- \*\*Development Tools:\*\* Eclipse IDE, Apache Tomcat

\- \*\*Database Connectivity:\*\* MySQL JDBC Driver



\## ⚙️ Prerequisites



Before running the project, install:



\- Java JDK

\- Eclipse IDE with Dynamic Web Project support

\- Apache Tomcat

\- MySQL Server

\- MySQL JDBC Driver



\## 🔧 Setup and Installation



1\. Clone or download this repository.

2\. Import the project into Eclipse.

3\. Configure Apache Tomcat in Eclipse.

4\. Create the MySQL database named "ludo\_food\_delivery".

5\. Execute the SQL scripts provided with the project to create the required tables and insert sample data.

6\. Update the database connection settings in your `DBConnection.java` file.

7\. Ensure the MySQL JDBC driver is available to the project.

8\. Run the application on Apache Tomcat.

9\. Open the application in your browser using the local URL provided by Tomcat.



\## 🎮 What Makes Ludo Food Delivery Different?



Unlike a conventional food delivery application, Ludo Food Delivery integrates a LUDO game with food ordering. Players can win discount coupons through gameplay, connecting entertainment with rewards and creating a more engaging ordering experience.
